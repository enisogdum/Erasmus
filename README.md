## 📚 Detailed Course Descriptions

### Big Data Analytics Tools and Software
* **Description:** An exploration of modern tools and frameworks used to process, analyze, and visualize massive datasets.
* **Main Topics:** Hadoop, Spark, NoSQL databases, data pipelines, data visualization.
* **Skills Gained:** Big Data processing, distributed computing, data engineering.
* **Folder:** `[Winter] Big Data Analytics`

### Database Systems
* **Description:** Core principles of designing, implementing, and managing relational database management systems.
* **Main Topics:** SQL, relational algebra, database normalization, transaction management, indexing.
* **Skills Gained:** Database design, SQL querying, data modeling.
* **Folder:** `[Winter] Database Systems`

### Dynamic Documents and Front-end Web Development
* **Description:** Building responsive, interactive, and dynamic user interfaces for the modern web.
* **Main Topics:** HTML5, CSS3, JavaScript, DOM manipulation, responsive design frameworks.
* **Skills Gained:** Front-end development, UI implementation, web accessibility.
* **Folder:** `[Winter] Dynamic Documents`

### E-commerce and Online Marketing Technologies
* **Description:** Technical and business aspects of developing electronic commerce platforms and digital marketing campaigns.
* **Main Topics:** E-commerce architectures, payment gateways, SEO/SEM, web analytics.
* **Skills Gained:** E-commerce platforms, digital marketing strategy, web analytics integration.
* **Folder:** `[Winter] E-commerce`

### Human-Computer Interaction
* **Description:** Studying the design, evaluation, and implementation of interactive computing systems for human use.
* **Main Topics:** UX/UI design principles, usability testing, cognitive psychology in design, prototyping.
* **Skills Gained:** User research, wireframing, UX evaluation, user-centered design.
* **Folder:** `[Winter] Human-Computer Interaction`

### Polish Language and Culture 1
* **Description:** An introductory course to the Polish language, accompanied by an exploration of Polish history and traditions.
* **Main Topics:** Basic vocabulary and grammar, conversational skills, cultural norms.
* **Skills Gained:** Intercultural communication, basic Polish proficiency.
* **Folder:** `[Winter] Polish Language`

### Entrepreneurship
* **Description:** Fundamentals of starting and managing a new business venture in the tech industry.
* **Main Topics:** Business models, startup methodologies, pitching, market research.
* **Skills Gained:** Business planning, entrepreneurial mindset, pitch presentation.
* **Folder:** `[Summer] Entrepreneurship`

### Intelligent Decision Systems
* **Description:** Designing systems that leverage data and algorithms to support complex decision-making processes.
* **Main Topics:** Decision theory, expert systems, rule-based logic, optimization algorithms.
* **Skills Gained:** Systems design, logical reasoning, decision modeling.
* **Folder:** `[Summer] Intelligent Decision Systems`

### Introduction to Artificial Intelligence
* **Description:** Foundational concepts and techniques in the field of Artificial Intelligence.
* **Main Topics:** Search algorithms, machine learning basics, neural networks, problem-solving through AI.
* **Skills Gained:** AI algorithms implementation, algorithmic thinking, basic ML modeling.
* **Folder:** `[Summer] Intro to AI`

### Introduction to Natural Language Processing
* **Description:** Techniques for enabling computers to understand, interpret, and generate human language.
* **Main Topics:** Text processing, sentiment analysis, language models, tokenization, semantics.
* **Skills Gained:** NLP pipelines, text mining, working with language data.
* **Folder:** `[Summer] Intro to NLP`

### Mobile Application Development
* **Description:** Creating robust and user-friendly mobile applications from scratch.
* **Main Topics:** Mobile UI design, native vs cross-platform development, mobile APIs, app lifecycle.
* **Skills Gained:** Mobile app programming, responsive mobile UI, app deployment.
* **Folder:** `[Summer] Mobile App Development`
