# Sudoku Solver – Best-First Search

Solves standard **9×9 Sudoku** puzzles using **Best-First Search** (via the SAC library). Generates children by filling the first empty cell with any digit that keeps the board legal, guided by a naive heuristic.

---

## Files

| File | Description |
|------|-------------|
| `src/ai/sudoku/Sudoku.java` | Board state, legality checking, child generation, and `main()` |
| `src/ai/sudoku/NaiveHeuristic.java` | Heuristic: number of unfilled cells (lower = closer to solution) |

---

## Algorithm

- **Best-First Search** with `GraphSearchConfigurator` set to find all solutions.
- Identifier type: `STRING` (each board state is identified by its string representation).
- Children are generated by placing each valid digit (1–9) into the first empty cell.

## Heuristic

`NaiveHeuristic` returns the count of zeros (empty cells) in the board. A lower value means fewer empty cells → higher priority in the search queue.

---

## How to Run

1. Add the SAC library `.jar` to your classpath.
2. Compile all `.java` files.
3. Run `ai.sudoku.Sudoku`.

**To solve a different puzzle**, change the `sudokuAsTxt` string in `Sudoku.main()`:
```java
// 81 digits, 0 = empty cell
String sudokuAsTxt = "003020600900305001001806400008102900700000008006708200002609500800203009005010300";
```
