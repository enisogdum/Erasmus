# week7: Exporting Figma Designs to HTML (Figma Plugins & TeleportHQ)

## 🎯 Task Objective
Experiment with export processes to turn a static Figma layout into a functional, working HTML/CSS page using two community plugins: **Figma to HTML** and **TeleportHQ**. Evaluate differences in conversion quality, layout behavior, and responsiveness.

---

## 🔌 Required Plugins & Tools
*   **Figma to HTML Plugin:** [Figma Community Link](https://www.figma.com/community/plugin/851183094275736358/)
*   **TeleportHQ Plugin:** [Figma Community Link](https://www.figma.com/community/plugin/992726161890204477/)
*   **TeleportHQ Platform:** [TeleportHQ Website](https://teleporthq.io/) (You can create a free account using a temporary email via `temp-mail.org` if desired).

---

## 🗂️ Project Stages

### 🔹 Stage 1: Exporting with the 'Figma to HTML' Plugin
1.  Open the Figma project containing the design mockup created in week6.
2.  Take a screenshot of the original mockup inside the Figma interface.
3.  Select the frame/content to export.
4.  Right-click -> **Plugins** -> **Manage plugins** -> Search and run **"Figma to HTML"**.
5.  Choose the **HTML (Legacy)** option, download the zipped project, and extract it.
6.  Open the converted webpage in a browser and compare it to the Figma version. Take screenshots and document any visual anomalies or differences.
7.  Open browser Developer Tools (`F12`), simulate different screen sizes (Phone, Tablet, Laptop), capture screenshots of each size, and note how the layout scales.

### 🔹 Stage 2: Exporting with 'TeleportHQ'
1.  Log in to your TeleportHQ account.
2.  In Figma, select the frame/content to export and launch the **TeleportHQ** plugin.
3.  Select one of the conversion methods:
    *   Copy the selected content to your clipboard and paste it into a new project in TeleportHQ.
    *   Create a new project directly through the plugin export interface.
4.  Open the project in TeleportHQ, capture a screenshot, and verify if it matches the Figma original.
5.  Click the **"</> Code"** button (top-right corner), navigate to the download drawer, choose **HTML**, and download the ZIP file.
6.  Extract the ZIP, open the HTML page in a browser, take screenshots, and document any conversion differences.
7.  Use DevTools to simulate Phone, Tablet, and Laptop screen sizes, capture screenshots, and assess responsive scaling.
