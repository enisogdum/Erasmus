# week1: Basic HTML Experiments & City Profiles

## 🎯 Task Objective
The task for today is to perform basic experiments with HTML using the official W3C tutorial and create two interconnected HTML documents featuring detailed information about two cities of your choice.

---

## 📚 Study Material
*   **W3C HTML Training Tutorial:** [Examine Sections: week1 & week2](https://www.w3.org/wiki/HTML/Training)
*   **HTML Reference Documents:** [HTML Standard (WHATWG)](https://html.spec.whatwg.org/multipage/)
*   **VS Code & HTML:** [How to use HTML within VS Code](https://code.visualstudio.com/docs/languages/html)

---

## 📋 Requirements & Deliverables

### 1. Two City Profile Documents
Prepare **two HTML documents** containing tables with information about two chosen cities (e.g., your birthplace, home town, current city of study, or any other city).

For each city, the HTML-based table must contain:
- [ ] **City/town name** (first row of the table).
- [ ] **Location** (country, region).
- [ ] **Position** (geographic coordinates).
- [ ] **Population**.
- [ ] **1 or 2 images** of the city.
- [ ] **Short description** (exactly 2 sentences explaining why you chose this city and what makes it unique/important).
- [ ] **Link to the official website** of the city (if it exists).

### 2. Styling & Layout Requirements
- [ ] **Cell Merging:** Utilize `colspan` or `rowspan` attributes (at least for the city name in the first row).
- [ ] **Formatting:** Apply basic HTML text formatting.
- [ ] **Interlinking:** Add a link at the top or bottom of each page pointing to the other document.

### 3. Submission
- [ ] Bundle all files (HTML files and images).
- [ ] Create a **ZIP archive** of your work.
- [ ] Submit the ZIP archive no later than **Tuesday**.

---

## 💡 Technical Notes & Tips
*   **Merging Cells:** To merge cells, investigate the `colspan` and `rowspan` attributes of the `<td>` or `<th>` element.
    *   Refer to the [MDN Web Docs on td element](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/td) for detailed usage instructions.
*   **Images:** For this exercise, you can use any images found online; there is no need to restrict your search to royalty-free assets.
