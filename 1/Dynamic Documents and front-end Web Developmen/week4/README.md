# week4: CSS Inheritance & Element Positioning

## 🎯 Task Objective
Perform two CSS exercises focusing on styling inheritance (nested lists) and element positioning (floating grid layouts with images).

---

## 🗂️ Exercise Breakdown

### 🔹 Exercise A: Styling Inheritance
1.  **Nested List Structure:** Prepare an HTML nested list with at least 3 levels and 2 items at each level (e.g., `Item A` -> `Item A.I` -> `Item A.I.1`).
2.  **General Styling:** Define a general, base style for the list containing several inherited properties (e.g., color, font-family).
3.  **Property Override:** Overrule inheritance by changing at least one single style property to a distinct value for each specific element level or element.
4.  **DevTools Inspection:** Take screenshots of the developer tools panel (e.g., Chrome DevTools) for at least **3 selected elements**, showing the computed styles and the order of inheritance.

### 🔹 Exercise B: Element Positioning & Floats
1.  **Assets Preparation:**
    *   Prepare **9 images** (100x100px) labeled with numbers 1 to 9 (or styled via borders/backgrounds to make dimensions visible).
    *   Prepare **1 special image** (110x110px) containing a letter and a distinct background color.
2.  **Webpage Setup:** Place all 9 numbered images sequentially in a webpage.
3.  **Floating Layouts:** By changing CSS positioning/floating properties, generate three layout orientations:
    *   **3x3 Grid**
    *   **In-line Flow** (one after another horizontally)
    *   **Column Flow** (one below another vertically)
4.  **Layout Disruption:** Insert the special 110x110px image somewhere in the middle of the sequence and analyze how it affects all 3 floating layouts.
5.  **Screenshots:** Capture screenshots of both the original (9 images) and modified (9 + special image) versions for all 3 layouts.

---

## 📋 Deliverables & Submission
Create a comprehensive report containing:
- [ ] Screenshots of all layout configurations (original and modified).
- [ ] DevTools inheritance inspection screenshots for Exercise A.
- [ ] Embedded HTML and CSS code.
