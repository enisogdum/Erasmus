# week9: Responsive UI Design with Bootstrap Components & Forms

## 🎯 Task Objective
Utilize the Bootstrap front-end framework to build a responsive, interactive questionnaire form and a separate webpage containing custom-styled Bootstrap components (Carousel and Accordion).

---

## 📖 Study & Setup
*   **Getting Started:** Read the [Bootstrap v5.3 Getting Started Guide](https://getbootstrap.com/docs/5.3/getting-started/).
*   **Responsive Layout:** Review [Bootstrap Grid & Layout System](https://getbootstrap.com/docs/5.3/layout/).
*   **Examples & Cheatsheet:** Explore [Bootstrap Examples](https://getbootstrap.com/docs/5.3/examples/) and reference the [Bootstrap Component Cheatsheet](https://getbootstrap.com/docs/5.3/examples/cheatsheet/).
*   **Forms Overview:** Review [Bootstrap Forms Guidelines](https://getbootstrap.com/docs/5.3/forms/overview/).
*   *Tip:* Start by using the Bootstrap "Starter template" to quickly scaffold your web pages.

---

## 🗂️ Project Tasks

### Task A: The Questionnaire Form
Create a webpage featuring a responsive questionnaire form styled with Bootstrap. The form must follow this hierarchical structure:

1.  **Personal & Role Info:**
    *   `Full name` (Text field, required).
    *   `Job title` (Text field, required).
    *   `Department` (Select dropdown).
    *   `Date` (Date picker, default = today's date).
2.  **Workload & Tasks:**
    *   `Average hours/week` (Select option: `<20`, `20–29`, `30–39`, `40+`).
    *   `Top task` (Text field).
    *   `% time on top task` (Number input, `0` to `100`).
    *   `Main activity type` (Select dropdown: *Project work, Meetings, Admin, Client-facing, Support, Other*).
    *   `Meetings frequency` (Select dropdown: *Daily, Weekly, Monthly, Rarely*).
3.  **Satisfaction & Issues:**
    *   `Overall satisfaction` (Radio buttons: *Very satisfied, Satisfied, Neutral, Dissatisfied*).
    *   `Biggest barrier` (Select dropdown: *Time, Resources, Priorities, Skills, Other*).
    *   `Comments` (Textarea, optional).
4.  **Follow-up & Consent:**
    *   `Want follow-up?` (Radio buttons: *Yes, No*).
    *   `Consent checkbox` ("I consent to take part in this workplace questionnaire", required).
5.  **Actions:**
    *   `Submit` button and `Save for later` button.

---

### Task B: Interactive Components & Restyling
Create a separate webpage containing the following two Bootstrap components:
*   **Carousel:** [Bootstrap Carousel Component](https://getbootstrap.com/docs/5.3/components/carousel/)
*   **Accordion:** [Bootstrap Accordion Component](https://getbootstrap.com/docs/5.3/components/accordion/)

#### Custom Styling:
1.  Verify the default (vanilla) look of the Accordion and Carousel.
2.  Override at least **2 CSS styles** for these components (e.g., custom colors, button designs, border radius, fonts, or active indicators).
3.  Capture screenshots **before** and **after** you apply the custom styles.
