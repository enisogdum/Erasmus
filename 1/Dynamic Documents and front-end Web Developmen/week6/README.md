# week6: Web Layout Design & Prototyping (Figma Grid Layout)

## 🎯 Task Objective
Create a visually appealing web layout mockup using Figma, utilizing layout grids to organize content components effectively.

---

## 🗂️ Project Steps

### 1. Conceptualization & Theme Choice
Select a website or web application concept that aligns with your goals. Possible concepts include:
*   **E-commerce Platform:** For a specific niche (e.g., handcrafted items, eco-friendly goods, tech products).
*   **Personal Portfolio:** Showcasing your projects, skills, biography, and contact info to future employers.
*   **Topic-focused Blog:** An online publication covering a specific interest (e.g., travel, programming, design).
*   **Web Application Interface:** A functional dashboard or control panel layout illustrating distinct features.

### 2. Define the Website Concept
Write a brief description (3–5 sentences) detailing:
*   The primary aims of the website.
*   The target user base.
*   The key functionalities and pages you plan to design.

### 3. Setup Figma & Layout Grids
*   Create or log into a Figma account.
*   Initialize a new frame (e.g., Desktop frame) and configure a structured **Layout Grid** (e.g., 12-column grid with standard margins and gutters) to align all visual blocks.
*   *Reference guide:* [Figma Best Practices: Everything you need to know about layout grids](https://www.figma.com/best-practices/everything-you-need-to-know-about-layout-grids/)

### 4. Design & Content Generation
*   Fill the grid layout with sample content, visual assets, headers, body copies, and buttons.
*   **Do not use placeholder text (Lorem Ipsum).** Use realistic, contextually relevant text (you can generate this using AI helpers if needed).

---

## 📋 Deliverables & Submission
Prepare a report in a single **PDF document** containing:
- [ ] The concept descriptions from Step 1 and Step 2.
- [ ] Exported images/screenshots of your high-fidelity Figma layout.
- [ ] Send/upload the PDF here.
