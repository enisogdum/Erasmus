# week12: Generative AI for E-commerce Creative Assets

## Task Overview
Experiment with Generative AI tools (specifically text-to-image models) to create customized graphic assets for highly niche/imaginary e-commerce scenarios.

---

## Step-by-Step Instructions

1.  **💡 Select Scenario Concepts:**
    *   Choose **3 out of the 4** following imaginary business scenarios:
        1.  *Webshop selling Jedi articles*
        2.  *Travel company selling tickets for space travel*
        3.  *Dating services for plush toys*
        4.  *Unicorn grooming services*

2.  **🎨 Select an AI Image Generator:**
    *   Use [Microsoft Designer Image Creator](https://designer.microsoft.com/image-creator) (recommended; use a standard personal account) or any other alternative (e.g., Midjourney, DALL-E, Stable Diffusion).

3.  **✍️ Prompt Engineering & Iteration:**
    *   For each of the 3 chosen scenarios, design text prompts to generate matching high-quality web graphics.
    *   Iterate on your prompts multiple times (e.g., tweaking descriptions, artistic styles, lighting, or details) to improve image quality.
    *   *Reference:* Review [Microsoft's Image Creator Prompting Guide](https://techcommunity.microsoft.com/blog/microsoft365insiderblog/create-stunning-visuals-with-image-creator-in-microsoft-designer/4225018) for tips.

4.  **🔎 Find Reference Stock Images:**
    *   Search the web using search engines for the best existing "stock image" that represents each scenario to use as a baseline/reference comparison.

5.  **📝 Analysis & Reflection:**
    *   Document the evolution of your prompts (explain why you modified specific words, styles, or concepts).
    *   Critique the final images: What are their strengths and weaknesses? Would they be acceptable for professional web publishing?

---

## Deliverables & Submission
*   Create a PDF report showing:
    *   Prompt iteration steps (the prompts used and the images generated).
    *   Comparison with the best-found reference stock image.
    *   Final comments on the quality and usability of the AI outputs.
*   Upload the report PDF to the assignment portal.
