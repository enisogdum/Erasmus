# week9: WooCommerce Analytics & Web Hosting Analysis

## Task Overview
This task concludes the WooCommerce exercises. You will perform a business analysis of your store using built-in WooCommerce Analytics, research and compare hosting environments (LAMP stack) for deploying production e-commerce applications, and prepare a domain and hosting budget.

---

## Step-by-Step Instructions

### Subtask I: WooCommerce Analytics
1.  **📊 Generate Reports:**
    *   Navigate to the **Analytics** menu in your WordPress admin dashboard.
    *   Access and analyze the following reports:
        *   **Overview Report:** High-level overview of store performance metrics.
        *   **Orders Report:** Analysis of orders placed, average order value, tax, etc.
        *   **Products Report:** Performance metrics of individual items sold.
2.  **📸 Documentation:**
    *   Take a screenshot of each of the three reports showing active metrics.
    *   *Reference:* Consult the [WooCommerce Analytics Documentation](https://woocommerce.com/document/woocommerce-analytics/) if you need assistance navigatig the charts.

---

### Subtask II: Web Hosting & Domain Analysis
1.  **💻 Hosting Provider Comparison:**
    *   Research **3 hosting companies** that support a standard **LAMP** (Linux, Apache, MySQL, PHP) stack.
    *   Compare them across **3 distinct hosting types**:
        1.  *Shared Hosting*
        2.  *Virtual Private Server (VPS)*
        3.  *Dedicated Server*
    *   Create a comparison table showing prices, contract duration/terms, included add-ons (SSL, backups, CDN), and hardware parameters (RAM, storage, bandwidth).

2.  **🌐 Domain Registration Plan:**
    *   Select **2 domain names** for your store idea:
        *   One global domain (e.g., `.com`, `.net`, `.org`)
        *   One country-specific top-level domain (e.g., `.pl`, `.de`, `.uk`)

3.  **💰 Budget Planning:**
    *   Create a budget plan forecasting the hosting and domain cost for **Year 1** versus **Year 2** (keeping in mind first-year promotional discounts vs. standard renewal rates).

---

## Deliverables & Submission
*   Combine the analytics screenshots and the hosting/budget report into a single PDF document.
*   Upload the report PDF to the assignment portal.
