# week14: E-commerce Recommendation Engines Evaluation

## Task Overview
This final exercise focuses on evaluating recommendation systems used by major e-commerce platforms (e.g., Amazon, eBay, Allegro) to understand how user-product relational data is leveraged to drive business metrics.

---

## E-commerce Recommendation Types
Recommendation engines commonly utilize several algorithms:
*   **🛒 Frequently Bought Together:** Suggesting complementary items purchased in the same transaction (e.g., camera + SD card) to increase Average Order Value (AOV).
*   **👥 Customers Who Bought This Also Bought:** Cross-selling items purchased by other buyers after viewing/buying the target product.
*   **👀 Customers Who Viewed This Also Viewed:** Displaying substitute or alternative products to help users compare.
*   **❤️ Recommended for You / Personal Pick:** User-level personalization based on browsing/purchase history.
*   **🔄 Compare with Similar Items:** Direct specification/price comparison tables for similar products in the same category.
*   **🔥 Trending / Best Sellers:** Platform-level popularity metrics (not personalized).
